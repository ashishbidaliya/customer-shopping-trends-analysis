# Customer Behavior Data Analytics

An end-to-end data analytics project focused on analyzing customer shopping behavior using Python, MySQL, SQL, and Power BI.

This project follows a real-world analytics workflow starting from raw data cleaning and preprocessing to SQL-based business analysis and interactive dashboard creation.

---

# Project Objective

The objective of this project is to analyze customer purchasing patterns and generate business insights related to:

- Customer spending behavior
- Product performance
- Subscription trends
- Discount usage
- Revenue contribution
- Customer segmentation

---

# Tech Stack

- Python
- Pandas
- NumPy
- MySQL
- SQLAlchemy
- Power BI
- Jupyter Notebook
- Git & GitHub

---

# Project Workflow

1. Data loading and preprocessing using Python
2. Data cleaning and feature engineering
3. Exporting cleaned data to MySQL
4. Business analysis using SQL queries
5. Building interactive Power BI dashboard
6. Creating business report and presentation deck
7. Publishing complete project on GitHub

# How to Run the Project

## Clone Repository

```bash
git clone <repository_link>
```

## Create Virtual Environment

```bash
python -m venv venv
```

## Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run Jupyter Notebook

```bash
jupyter notebook
```
